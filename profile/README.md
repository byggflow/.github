Byggflow builds open-source tools and infrastructure for developers. Our mission is to create software that solves hard problems simply, giving teams the building blocks to ship faster without trading away control.

## What We Do

Byggflow develops developer tools, runtimes, and platforms. We focus on the systems that sit underneath the products people build — the layers that need to be fast, reliable, and easy to integrate. Everything we make is open-source and designed to run on your own terms.

## Our Repositories

Our repositories host the source code for the various projects under Byggflow. Each repository includes detailed documentation and guidelines for contribution.
